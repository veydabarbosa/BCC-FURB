# Avaliação 3 - Programação Web I

## Sobre o projeto:

Este projeto foi desenvolvido como parte da **Avaliação 3** da disciplina **Programação Web I**, do curso de **Bacharelado em Ciência da Computação** da **Universidade Regional de Blumenau (FURB)**.

O objetivo da atividade foi aplicar os conceitos estudados ao longo da disciplina por meio do desenvolvimento de uma aplicação web utilizando o framework **Angular**, explorando a arquitetura baseada em componentes, roteamento, comunicação entre componentes, consumo de dados e demais recursos disponibilizados pela plataforma.

## Objetivos da avaliação:

- Desenvolver uma aplicação utilizando Angular;
- Aplicar os conceitos de componentes, módulos e templates;
- Utilizar data binding e diretivas;
- Implementar navegação entre páginas quando necessário;
- Organizar o projeto seguindo boas práticas de estruturação;
- Consolidar os conhecimentos adquiridos durante a disciplina.

## Tecnologias utilizadas:

- Angular
- TypeScript
- HTML5
- CSS3
- Node.js
- npm

## Como executar o projeto:

### 1. Clonar o repositório

```bash
git clone https://github.com/veydabarbosa/BCC-FURB.git
```

### 2. Acessar a pasta do projeto:

```bash
cd "3º SEMESTRE/Programação Web I/Avaliação 3/avaliacao3-web"
```

### 3. Instalar as dependências:

```bash
npm install
```

### 4. Executar a aplicação:

```bash
ng serve
```

Caso o Angular CLI não esteja instalado globalmente:

```bash
npx ng serve
```

### 5. Acessar no navegador:

```
http://localhost:4200
```
